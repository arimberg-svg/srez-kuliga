# Срез знаний. Кулига

Страница: https://arimberg-svg.github.io/srez-kuliga/

40 вопросов для магазина №23, село Кулига. Четыре блока по 10: компания, юрлица, касса, склад. Норма — 8 из 10 в каждом блоке. На сдачу 40 минут, попытка одна.

В списке: Баев Андрей, Шихалев Вячеслав, Коноплич Сергей и Римберг Александра. Результат уходит на arimberg@gmail.com.

Вопросы собраны из книги сотрудника, помощи до машины, «Посоветуй Михалыча», мёртвого стока, регламента по реализациям и доверенностям, возврата, лимита кассы, чек-листа кассира и чек-листа СПК по схеме 5+1, неделя кладовщика.

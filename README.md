# Срез знаний. Кулига

Страница: https://arimberg-svg.github.io/srez-kuliga/

40 вопросов для магазина №23, село Кулига. Четыре блока по 10: компания, юрлица, касса, склад. Норма — 8 из 10 в каждом блоке. На сдачу 40 минут, попытка одна.

В списке: Баев Андрей, Шихалев Вячеслав, Коноплич Сергей и Римберг Александра. Результат уходит на a.rimberg@um-ural.ru.

Вопросы собраны из опубликованных инструкций: книга сотрудника и кодекс, помощь до машины, «Посоветуй Михалыча», мёртвый сток, регламент реализаций и доверенностей, возврат товара, лимит кассы, чек-лист кассира, добор товара на кассе от 11 ноября 2026, погрешность по метизам, журнал заказов на перемещение.

# Срез знаний. Кулига

Страница: https://arimberg-svg.github.io/srez-kuliga/

45 вопросов для магазина №23, село Кулига: компания, юрлица, касса, склад. Норма — восемь верных из десяти в каждом блоке. На сдачу 45 минут, попытка одна.

В списке: Баев Андрей, Шихалев Вячеслав, Коноплич Сергей и Римберг Александра. Результат уходит на arimberg@gmail.com.

Вопросы собраны из книги сотрудника, помощи до машины, «Посоветуй Михалыча», мёртвого стока, регламента по реализациям и доверенностям, возврата, лимита кассы, чек-листа кассира, чек-листа СПК по схеме 5+1, корпоративной цены для сотрудников, недельного пакета документов и правил по торговому оборудованию.
